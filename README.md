# KASIR SB PWA

Paket halaman instalasi PWA KASIR SB.

## Cara menerbitkan di GitHub Pages
1. Buat repositori baru bernama `kasir-sb-pwa`.
2. Unggah seluruh isi folder ini ke root repositori (bukan folder pembungkus).
3. Pada Settings > Pages, pilih Deploy from a branch, branch `main`, folder `/(root)`.
4. Tunggu GitHub Pages aktif. URL yang diharapkan:
   https://rtrw003009-cyber.github.io/kasir-sb-pwa/
5. Buka URL tersebut di Chrome Android untuk menguji halaman dan opsi instalasi.

Tombol Buka Aplikasi Kasir tetap menuju deployment Google Apps Script yang sudah ada.
Paket ini tidak mengubah Google Sheets atau kode aplikasi kasir.
